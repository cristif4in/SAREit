What is this:
SAREit is a lightweight from 0, git platform that supports actual git commands to be ran and all, hostable even on http://127.0.0.1/ for example.
Backend is Node.js, using SQLite as it's primary database for repos/accounts as of now.

How do i start using it:
You can download the source as it is right now, preferably with git clone or just the .zip and then upload the files to your host, and just start the index.js and have fun.

Why??:
Because imo there's no straightforward git platforms to just take and use immediately, this one does this.

Did you use AI:
Yes

Security questions:
To know how protected you are, that's on you, SAREit poses no known public keys/passwords/sensitive information as much as i know, we will make it more server-side as we advance.
